# Focus Flow 🌊

A minimal Pomodoro-style focus timer with task tracking, built as a single self-contained HTML file — no build step, no dependencies.

## Features

- Focus/break timer with a circular progress ring (25/15/45 minute presets)
- Task list: add, mark done, delete, and set an active task for the current session
- Stats: pomodoros completed today and all-time, tasks done, and a daily streak counter
- State is saved to `localStorage`, so tasks and stats persist across reloads
- Light/dark theme, following your system preference

## Usage

Just open [`index.html`](index.html) in a browser — no installation or server required.

```bash
open index.html
```

(On Windows: `start index.html`. On Linux: `xdg-open index.html`.)
